# Stage 4: the MCP server — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude and ChatGPT connect to Lukitas over OAuth, read the person's month and write, fix
and delete movements through a remote MCP server; the person sees and revokes them from Ajustes.

**Architecture:** The API learns to accept OAuth access tokens (JWTs from Better Auth's
`oauthProvider`, audience = the MCP URL) next to sessions, with scopes and `source = mcp`.
`packages/ai-assistant-tools` holds the tools against a `Lukitas` interface, tested with an
in-memory one. `apps/mcp` is a stateless Hono service that checks the token, builds an
`ApiLukitas` with it and serves the tools with the SDK's `createMcpHandler` (2026-07-28 and the
2025-11-25 fallback).

**Tech Stack:** Better Auth 1.7.11 (`oauthProvider`, `jwt`) + `@better-auth/cimd` 1.7.11;
`@modelcontextprotocol/server` 2.3.1 + `@modelcontextprotocol/client` 2.3.1 (tests); Hono;
openapi-fetch; zod 4; vitest; React Router (web); Flutter (app).

**Spec:** `docs/superpowers/specs/2026-10-29-stage-4-mcp-design.md`

## Global Constraints

- MCP revision **2026-07-28**, plus **2025-11-25** through the SDK's stateless legacy serving.
- Scopes: `finance:read`, `finance:write`, `offline_access` (already `OAUTH_SCOPES`).
- Access tokens live **15 minutes** (`accessTokenExpiresIn: 900`); refresh tokens until revoked.
- Write calls take **1 to 50** items; list pages hold **100**.
- Idempotency window for `add_transactions`: **10 minutes**.
- Tool names in English; answers in the person's locale (es, en, it, pt) and currency.
- Dependencies at least two weeks old where a choice exists (hence 1.7.11 / 2.3.1, not the
  newest): `@better-auth/cimd` 1.7.11 matches the installed `better-auth` 1.7.11, so no upgrade.
- New config `MCP_URL` (the MCP's public URL, its RFC 8707 resource id) in both API and MCP.
- No Claude co-author lines in commits (founder's global rule).

## Review Focus

1. **A token for another audience or a revoked assistant** must not open `/v1/*`: a session-less
   JWT signed by us but for no resource, or for the API itself, is refused; revoking deletes the
   refresh tokens so the next refresh fails. (Task 1 tests.)
2. **A `finance:read` token calling a write route** gets 403 `insufficient_scope`, and an OAuth
   token never reaches account-level routes (delete account, export, imports, claim email).
   (Task 1 tests.)
3. **Amounts the model sends with decimals or as negative numbers** ("18.5", -18000): the tool
   rounds to the currency's minor units and takes the sign from `kind` only. (Task 3 tests.)
4. **A category name with accents or another case, or matching two categories**
   ("comida" vs "Comida rápida" vs "Comidá"): exact normalized match wins; otherwise one
   prefix/substring match is used; several → an error listing them. (Task 3 tests.)
5. **A retry of `add_transactions` after a broken stream** saves once and says "ya estaba
   guardado"; a batch of 50 crosses the API's 20-item batch limit in chunks that are each
   idempotent. (Task 3 tests.)
