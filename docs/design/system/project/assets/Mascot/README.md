# Mascot

`lukas-mascot-concept.webp` is the concept sheet for Lukitas, generated with an image model and chosen by the founder: happy (waving), worried (sweat drop, budget alert) and celebrating (jumping with sparkles), on the night background. It is reference art: the production 3D model and the per-mood app assets are made from it. Do not crop it into UI; use the per-mood assets once they exist.
