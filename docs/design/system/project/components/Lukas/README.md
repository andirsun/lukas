# Lukas

The mascot, a 3D gold coin whose mood mirrors the budget. Consumer provides `mood`: `happy` (all categories ok, or right after logging), `worried` (any category near or over), `celebrating` (save, paid, month closed in green).

- Landing: `Lukas3D`, a live model that looks at the pointer and travels with the scroll; replaced by a still under `prefers-reduced-motion` or without WebGL.
- App: a lightweight 2D rendering beside a `lk-bubble` with the rule-based message.
- The art shown is concept art; final per-mood assets replace it without code changes.
